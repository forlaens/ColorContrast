# Color Contrast

Image contrast checker web app.

## Project layout

- `app/` contains the production PHP, CSS, JavaScript, and image assets.
- `scripts/` contains the npm build and validation helpers.
- `test/` contains automated tests for the build output.
- `dist/` is generated by the build and should be deployed as the web root. It contains rendered static HTML plus public assets, not PHP source.

## Commands

```sh
npm run dev
npm run check
npm run test:structure
npm run test:accessibility
npm test
npm run build
npm run clean
```

`npm run dev` serves `app/` at `http://127.0.0.1:8000`.

`npm run test:structure` builds the static app and checks rendered HTML structure, including headings, landmarks, footer links, and PWA metadata.

`npm run test:accessibility` builds the static app and runs Siteimprove Alfa plus axe-core checks through Playwright.

`npm test` runs the full local test suite.

Set `SITE_URL` when building for production so social media card URLs use the deployed domain:

```sh
SITE_URL=https://example.com npm run build
```
